Topic 1: Artificial Intelligence

Building systems that perform tasks associated with human intelligence.

What it is [Slide]

AI is defined by what the system does (behavior needing intelligence), not by how it is built. It is an umbrella field encompassing many techniques.

Why it exists

To automate complex tasks (perception, reasoning, learning, language, planning, decision-making) beyond literal instruction execution.

Capabilities & Examples

  • Perception: Image recognition
  • Reasoning: Rule-based Expert Systems
  • Language: Chatbots
  • Decision-making: Game-playing agents

Trap: AI ≠ ML

A system following hand-written if-else rules (Expert System) to diagnose illness is AI (it reasons), but it is not ML (it learns nothing from data).

Topic 2: Machine Learning

"The field of study that gives computers the ability to learn without being explicitly programmed." — Arthur Samuel

Classical Programming vs ML [Ext]

Classical: Rules + Data → Answers

ML: Data + Answers → Rules (Model)

The algorithm learns useful patterns from data rather than relying on manual rules. The goal is to make predictions on new, unseen cases (Generalization).

Exam Practice

Q: What does the computer "learn", and what does the programmer actually program?

Answer: The computer learns the decision rules (parameters) from the data. The programmer programs the learning procedure (e.g., optimization algorithm), data pipeline, and architecture, not the specific if-then logic.

Trap: "Zero human intervention"

The slides say minimal human intervention. Humans still define the problem, clean data, engineer features, and evaluate metrics. The algorithm only replaces the manual rule-writing.

Topic 2 Math: How "Learning" Actually Works

Learning is an optimization process: finding parameters (θ) that minimize a Cost function.

J(θ) = (1/m) ∑ (ŷ - y)²
θ ← θ - α · (∂J/∂θ)

Topic 3: AI vs ML vs DL vs GenAI

Nested hierarchies of intelligent systems.

Artificial Intelligence (AI)
Machine Learning (ML)
Deep Learning (DL)
Generative AI
  • AI: The umbrella. (e.g. Rule-based Expert System).
  • ML: Learns from data. (e.g. Linear Regression).
  • DL: Subset of ML based on multi-layer neural networks.
    Math Ext: Multiple layers allow hierarchical feature extraction (edges→shapes). Needs non-linear activation (ReLU) otherwise layers collapse into one linear map.
  • GenAI: Subset of DL that generates new content (text/images) instead of just classifying it.

Topics 4 & 5: Why ML? & Terminology

Why choose ML over traditional code?

  • Rules hard to specify: e.g., Spam. You can't code every possible spam word.
  • Hidden patterns in large data: Humans can't see trends in millions of rows; algorithms can.
  • Changing environment: Fraudsters adapt. Manual rules go stale, but ML can be retrained.
When NOT to use ML

If rules are simple, 100% exact (like tax math), or if you have zero data.

Core Terminology

  • Feature: Input variable (House size).
  • Label/Target: Desired output (House price).
  • Model: The learned patterns.

Training vs. Inference [Ext]

Training: Fits model to data. Expensive, uses features + labels to adjust parameters.

Inference: Uses trained model on new data. Cheap, uses ONLY features (no labels), parameters are fixed.

Defined by the type of feedback the algorithm receives.

Unsupervised No feedback (Unlabelled data) Discover structure/groups Clustering, Association

Topic 7: Supervised Learning (Reg vs Class)

Regression

Predicts a continuous numerical output.

Example: Housing price based on size.

Math: h(x) = θ0 + θ1x. Fits a smooth curve to generalize, minimizing Mean Squared Error.

Classification

Predicts a discrete category.

Example: Tumour is Malignant (1) or Benign (0).

Math: Finds a decision boundary (line for 2 features). Uses Sigmoid to squash scores to probabilities.

Trap: Classification is determined by the output being categorical, not the input. You can use continuous inputs (tumour size, age) to predict a discrete class (0/1).

Topic 8: Unsupervised Learning

Deriving structure from data with no predefined labels or feedback.

Clustering

Grouping items so members of a group are more similar to each other than to other groups.

App: Google News grouping articles; Customer Personas.

Association

Finding items that occur together ("customers who buy A often buy B").

App: Checkout recommendations (Cross-selling).

Math Ext: Distance

Clustering relies on distance (e.g., Euclidean: d = √∑(ak - bk)²). This is exactly why Scaling is required—otherwise, large-numbered features dominate the distance calculation.

Clustering ≠ Classification

Clustering discovers un-named groupings organically. Classification learns to map data to predefined, human-labelled classes.

Topic 9: Reinforcement Learning (RL)

An autonomous agent learns optimal decisions by interacting with an environment through trial and error.

The RL Loop

Observe current State (s).
Act using Policy (a).
Measure next state & Reward (R).
Update strategy.

Example: Waymo self-driving car (Agent) in traffic (Environment). Reward = +1 for moving safely, -100 for crash.

Exploration vs Exploitation

Explore: Try random actions to find better strategies (risks immediate reward).
Exploit: Use known good actions (risks missing the global best).

Math (ε-greedy): Random action with prob ε, best action with 1-ε.

Long-term vs Immediate [Ext]

RL maximizes cumulative long-term reward (Return G = r1 + γr2 + γ²r3...). The discount factor (γ < 1) makes sooner rewards worth more. This is why Netflix optimizes for long-term engagement over a single click.

Topic 10: General ML Workflow

  1. Define problem
  2. Collect & understand data
  3. Preprocess (Topic 11)
  4. Split data (Train/Val/Test)
  5. Select model
  6. Train
  7. Validate (tune/detect overfitting)
  8. Test (final check)
  9. Deploy & Monitor
Data Splitting [Ext]

Train: Fit parameters.
Validation: Tune hyperparameters & check overfitting.
Test: Unbiased final test. Touch only once! (Data Leakage if reused).

Metric Choice

Accuracy fails on imbalanced data (e.g., 99% benign tumours). Need Precision/Recall. Metric must reflect the business objective.

Data Drift

Why monitor? The real-world environment changes over time. Models must be retrained to stay relevant.

Topics 11.1 - 11.4: Preprocessing & Data Quality

11.2 Quality

Issues: missing values, duplicates, inconsistent units (kg vs lb), impossible values (-5 age). Must document cleaning choices to avoid hidden biases.

11.4 Outliers

Not all outliers are errors. In fraud or anomaly detection, outliers are the signal. Math detection: z-score > 3, or outside 1.5 * IQR.

11.3 Missing Values

  • Deletion: Fine if MCAR, bad if missingness is a signal (e.g., rich people skip income).
  • Mean Imputation: Bad if data has outliers.
  • Median Imputation: Robust to outliers.
  • Model Imputation: Use other columns to predict missing value.

Math Example: Mean vs Median

Data: [5, 6, 7, 8, 100]. Mean = 25.2. Median = 7.
Imputing a missing value with 25.2 misrepresents the typical item. Median is better here.

Topic 11.5: Scaling (Standardization vs Min-Max)

Scaling is mandatory for distance-based (k-NN) and gradient-based algorithms.

Standardization: z = (x - μ) / σ
Min-Max: x' = (x - min) / (max - min)

Topics 11.6 & 11.7: Encoding and Feature Engineering

11.6 Categorical Variables

Algorithms only understand numbers. If you encode City names as (Paris=1, London=2, Tokyo=3), the model assumes Tokyo > Paris and calculates false distances.

Solution: One-Hot Encoding
Paris = [1,0,0], London = [0,1,0]. Keeps categories equidistant.

Ordinal Encoding: Acceptable for (Low=1, Med=2, High=3) because order exists.

11.7 Feature Engineering

Transforming raw info into useful signals.

  • Dates: Extract Month/Day (captures seasonality).
  • Birth year: Calculate Age (what actually matters).
  • Ratios: Price / Sq Ft, or BMI (Weight/Height²). Captures complex relationships a basic model can't easily build itself.

Trap: Leakage [Ext]

Scaling parameters (μ, σ, min, max) and Encoders must be fit on the Training Set ONLY, and then applied to Validation/Test sets. Doing it on the whole dataset leaks future information into training.

Conceptual Question Bank (Selected)

Q: Bank fraud is 0.1% of data. Which learning type, metric, and handle outliers?

Classification / Anomaly Detection. Metric: Recall or F1 (Accuracy misleadingly reads 99.9%). Keep outliers, they are the fraud!

Q: Why is "will it rain: yes/no" classification but "how many mm" regression?

Because supervised types are determined by the OUTPUT, not the input features.

Q: Why fit a smooth curve for housing instead of joining all dots?

Joining dots memorizes noise (Overfitting). A smooth curve generalizes to unseen data.

Q: What happens in RL with ε = 0?

Pure exploitation. The agent never explores, potentially getting stuck in a sub-optimal strategy forever.

Q: Why split before scaling?

To prevent test set statistics (min, max, mean) from leaking into the training process.
