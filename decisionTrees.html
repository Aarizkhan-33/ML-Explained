Introduction to Decision Trees

A supervised machine learning algorithm for classification and regression that mirrors human decision-making by splitting data into smaller subsets based on rules.

Anatomy of a Tree

  • Root Node: Top node, entire dataset, first split.
  • Internal Node: Sub-nodes testing specific conditions.
  • Leaf Node: Final endpoints containing predicted outcome.

The Mathematics of Purity: Entropy

Entropy measures the messiness or randomness of data (0 = perfect purity, 1 = maximum mix).

Entropy(S) = - Σ (pi * log2(pi))

10 Patients: 6 High Risk, 4 Low Risk

  • 1. Find Class Probabilities
    Formula: p = class_count / total
    Why: We need the ratio of each class to measure the mix.
    p(High) = 6/10 = 0.6 | p(Low) = 4/10 = 0.4
  • 2. Calculate High Risk Penalty
    Formula: - p * log₂(p)
    Why: The Logarithm heavily penalizes evenly mixed data.
    -0.6 * log₂(0.6) = 0.442
  • 3. Calculate Low Risk Penalty
    Formula: - p * log₂(p)
    -0.4 * log₂(0.4) = 0.529
  • 4. Total Entropy (Sum)
    Formula: Sum of all class penalties
    Why: Combining them gives the total dataset messiness (0 to 1).
    0.442 + 0.529 = 0.971
    Result is close to 1, meaning data is highly mixed!

Splitting the Data: Information Gain

Information Gain is the reduction in entropy after applying a rule. The tree picks the rule with the highest gain.

Info Gain = Entropy(Parent) - Σ (Weight of Child * Entropy(Child))

Parent (Entropy = 0.971)

Left Child (Yes)

Right Child (No)

  • 1. Parent Entropy Baseline
    Why: We need to know how messy data was before splitting.
    Parent Entropy = 0.971
  • 2. Evaluate Left Child
    Formula: Weight = Child_Count / Total_Count
    Why: Catches all 6 High Risk. It's 100% pure (Entropy=0).
    Weight = 6/10 (0.6). Entropy = 0.
  • 3. Evaluate Right Child
    Why: Catches all 4 Low Risk. It's 100% pure (Entropy=0).
    Weight = 4/10 (0.4). Entropy = 0.
  • 4. Calculate Information Gain
    Gain = Parent - [ (W_left * E_left) + (W_right * E_right) ]
    Why: Shows how much "purity" we gained from this split.
    0.971 - [ (0.6 * 0) + (0.4 * 0) ] = 0.971
    Perfect Split! The tree will choose this rule.

A Faster Metric: Gini Impurity

Similar to Entropy, but computationally faster because it uses squaring instead of logarithms. Ranges from 0 (pure) to 0.5 (maximum mix for binary classification).

Gini(S) = 1 - Σ (pi)2

Same 10 Patients (6 High, 4 Low)

  • 1. Find Probabilities
    p(High) = 0.6 | p(Low) = 0.4
  • 2. Square the Probabilities
    Formula: p²
    Why: Squaring penalizes smaller probabilities quickly, replacing the heavy log math.
    0.6² = 0.36 | 0.4² = 0.16
  • 3. Sum the Squares
    0.36 + 0.16 = 0.52
  • 4. Calculate Gini
    Formula: 1 - Sum
    Why: Subtracting from 1 flips the scale so 0 = pure and 0.5 = mixed.
    1 - 0.52 = 0.48
    Close to 0.5 max = Highly mixed!

Overfitting & Cost-Complexity Pruning

Trees that grow too deep memorize noise (overfitting). Pruning chops off weak branches to improve generalization on unseen data.

Cost = R(T) + (α * |T|)
R(T) = Error count | |T| = Number of leaves | α = Penalty per leaf

    Why: Complex tree has low error (15) but high complexity (10 leaves). Penalty alpha is 2.
    Cost = 15 + (2 * 10) = 35
  • 2. Pruned Tree Score
    Why: Pruning chops weak leaves. Errors go up slightly (16), but complexity drops massively (5 leaves).
    Cost = 16 + (2 * 5) = 26

    Result: 26 < 35. The algorithm prefers the smaller, pruned tree!

Wisdom of Crowds: Random Forests

Fixes single-tree overfitting by building hundreds of independent trees and averaging their predictions.

Mechanism 1: Bootstrapping (Row Randomness)

Draw N rows randomly with replacement. Each tree only sees ~63.2% of the original data, leaving 36.8% as Out-of-Bag (OOB) test data.

Mechanism 2: Feature Subsetting (Column Randomness)

Instead of looking at all features M, each tree looks at a random subset m to prevent correlation (trees making the same mistakes).

  • Classification: m = √M (e.g., 100 cols → 10 cols)
  • Regression: m = M/3 (e.g., 100 cols → 33 cols)
