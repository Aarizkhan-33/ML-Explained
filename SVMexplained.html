EXPLANATION

2. The "C Story"

A High C boss hates mistakes, squeezing the margin street narrow to perfectly separate teams.

A Low C boss wants a robust, wide street, shrugging if a few players stand on the wrong side.

Because the Low C street is wider, more players touch it, creating more Support Vectors.

Quick Synthesis:

• High C → Strict → Narrow street → Fewer Support Vectors → Overfit risk.

• Low C → Tolerant → Wide street → More Support Vectors → Robust generalisation.

3. "What changes if…" Drills & 4. Compare Pairs

Slide 12 / 14

3. "What changes if…" Drills

C goes up: Margin becomes narrower; fewer support vectors; higher overfitting risk.
C goes down: Margin becomes wider; more support vectors; better generalisation.
One outlier added (Hard Margin): The math completely breaks or severely overfits.
One outlier added (Soft Margin): The slack variable absorbs it; boundary barely shifts.
A non-support-vector is deleted: Absolutely nothing happens to the model.
A support vector is deleted: The margin expands and the boundary shifts.
Features are unscaled: Large-numbered features dominate the distance, warping the boundary.
γ is huge: Influence shrinks to local islands; boundary becomes highly wiggly.
Kernel switches linear → RBF: Boundary goes from a straight flat plane to a warped curve.

4. Compare Pairs

Hard vs Soft margin:

Zero tolerance for crossing lines vs allowing penalized slack.

OvR vs OvO:

N models tested against the rest vs N(N-1)/2 pairwise duels.

SVM vs SVR:

Separates classes to maximize margin vs fits data inside a tolerance tube.

Linear vs RBF kernel:

Draws straight lines in current space vs bends space using distance similarity.

Kernel trick vs Explicit mapping:

Calculating dot products mathematically vs actually building massive coordinates.

5. 12 Exam-Style Questions

Slide 13 / 14

1. Why does SVM maximize the margin?

It provides the best generalisation against future noise.

2. Why are they called support vectors?

Because they "support" the margin; deleting others changes nothing.

3. Why do we use the kernel trick?

Mapping to infinite dimensions explicitly is computationally impossible.

4. Why does unscaled data ruin SVM?

SVM uses geometric distance; larger numbers overpower the math.

5. Why use SVR instead of standard linear regression?

SVR ignores minor errors inside the ε-tube, creating smoother fits.

6. Why might a Soft Margin model perform better than Hard Margin?

Real data has noise; Hard Margin overfits it.

7. How does C control overfitting?

High C strictly penalizes errors, forcing a tight, overfitted boundary.

8. How does OvO handle multi-class predictions?

It pits every class against every other class in a voting tournament.

9. How do you widen the margin mathematically?

By minimising the magnitude of the weight vector w.

10. How does the RBF kernel define similarity?

Similarity drops exponentially as geometric distance between points increases.

11. What happens if you lower C?

The margin widens, increasing the number of support vectors.

12. What happens if you increase Gamma (γ)?

The decision boundary becomes tighter and highly wiggly.
