Foundations

Topic 1: Introduction to SVM

A gold-standard algorithm delivering robust, principled learning for both linear and non-linear spaces.

Core Philosophy

SVM is a very powerful algorithm widely used in both industry and academia.

Compared to logistic regression and neural networks, the Support Vector Machine sometimes gives a cleaner, and sometimes more powerful way of learning complex non-linear functions.

Linear Models & Deep Networks

Standard Approaches

  • Boundary placement: Often draws any line that separates data (e.g. Perceptron) without maximizing the buffer. It may pass dangerously close to training points.
  • Optimization challenge: Neural networks optimize complex, non-convex loss functions subject to local minima, saddle points, and vanishing gradients.
  • Non-linear boundaries: Require manual polynomial feature engineering or stacking multiple deep layers with massive amounts of training data.
Support Vector Machines

The SVM Advantage

  • Maximal Margin: Explicitly optimizes for the widest possible safety cushion ("street") between classes, providing strong mathematical guarantees.
  • Global Convex Optimum: Formulated as a Quadratic Programming (QP) problem. Has a single unique global minimum—zero risk of getting trapped in local minima!
  • The Kernel Trick: Projects data into infinite-dimensional spaces implicitly with zero high-dimensional coordinate computation.
  • Extreme Sparsity: The final decision boundary depends strictly on a tiny subset of points (Support Vectors); all other training examples can be safely removed.

Geometry & Optimization

Topic 2: The Decision Boundary & Margin

How SVM identifies the uniquely optimal separating hyperplane among infinitely many candidates.

The Margin

SVM looks for the decision boundary (the black line) that has the larger minimum distance from any of the training examples.

Other algorithms might draw lines that come too close to training examples. SVM separates data with as large a margin as possible, providing robustness. Therefore, it is often called a large margin classifier.

Support Vectors

Support Vectors: These are the critical data points that lie directly on the margins. If you remove all other data points from the dataset, the decision boundary stays exactly the same. They completely define the model.

Why Maximize Margin?

It provides the best generalization. A wider street means the model is less sensitive to slight noise or variations in future test data.

The margin width equals 2 / ||w||. Maximizing the margin is mathematically equivalent to minimizing ½ ||w||².

● Class +1 ● Class -1 -- Margins ◎ Support Vectors

High-Dimensional Transformation

Topic 3: The Kernel Trick & Non-Linear SVM

Overcoming non-linearly separable data without suffering from the curse of dimensionality.

1. The Problem

When data cannot be split by a straight line in its current dimension.

2. The Solution

We transform the features into a higher-dimensional space where they become linearly separable (e.g., if 2D is inseparable, adding a 3rd dimension might reveal a gap between classes where a separating hyperplane can be drawn).

3. The Computational Barrier

The Computational Barrier: Mapping thousands of points into a high-dimensional (or infinite) space makes calculating distances computationally impossible.

4. The Kernel

The Kernel: A mathematical function that solves this computing problem. It computes dot products in the target space directly from original inputs: K(x, z) = ⟨φ(x), φ(z)⟩.

Standard Reference

Popular Kernels

Popular kernels include: Linear Kernel, Polynomial Kernel, Gaussian Kernel, Radial Basis Function (RBF), Laplace RBF Kernel, and Sigmoid Kernel.

Linear Kernel K(x, z) = xᵀz + c
Polynomial Kernel K(x, z) = (xᵀz + c)ᵈ
Gaussian Kernel K(x, z) = exp(-γ ||x - z||²)
Radial Basis Function (RBF) Infinite-dimensional Hilbert projection
Laplace RBF Kernel K(x, z) = exp(-γ ||x - z||)
Sigmoid Kernel K(x, z) = tanh(α xᵀz + c)

Extensions (Part 1)

Topic 4: Multi-Class SVM

Extending the binary margin classifier to handle datasets with 3 or more target classes.

Core Architecture

SVM is natively a binary (two-class) classifier. To handle multi-class problems, two strategies are used:

Strategy 1

One-vs-Rest (OvR)

One-vs-Rest (OvR): Trains one classifier per class against all other classes combined. The class with the highest confidence score wins.

Key Characteristics:

  • Model Count: Exactly N binary models for N classes.
  • Decision Rule: Evaluates decision function fᵢ(x) = wᵢᵀx + bᵢ; argmax wins.
  • Speed: Highly scalable and fast to train. Standard in LinearSVC.
  • Potential Issue: Asymmetry and class imbalance (1 class vs N-1 classes).
Strategy 2

One-vs-One (OvO)

One-vs-One (OvO): Trains a classifier for every possible pair of classes (N(N-1)/2 models). A voting system determines the winner.

Key Characteristics:

  • Model Count: N(N-1) / 2 pairwise binary models.
  • Decision Rule: Each pair votes; the class accumulating the most votes wins.
  • Imbalance Robustness: Balanced training since each model only sees two classes.
  • Implementation: Default behavior in Scikit-Learn's kernel SVC.

Extensions (Part 2)

Topic 5: Support Vector Regression (SVR)

Reversing the classification principle to fit continuous target functions with sparse support vectors.

Reversing The Objective

Fitting Instead of Separating

Instead of finding a line that separates classes, SVR finds a line that fits the data.

It reverses the objective: it maximizes the margin while ensuring that as many data points as possible fall inside a tube around the line (defined by a tolerance threshold ε).

min ½||w||² + C ∑(ξᵢ + ξᵢ*)   s.t. |yᵢ - (wᵀxᵢ + b)| ≤ ε + ξᵢ
Mechanism

The ε-Insensitive Loss Function

  • Zero Loss Inside Tube: Any prediction error smaller than ε has a cost of exactly 0! Points inside the tube are completely ignored.
  • Slack Penalty Outside Tube: Points deviating beyond the ε-band incur a linear penalty (ξᵢ above the tube, ξᵢ* below the tube).
  • Sparse Representation: Just like in classification, only data points falling on or outside the ε-tube boundary become Support Vectors!
  • Outlier Robustness: Because the loss penalty is linear (L1) rather than squared (L2), SVR is immune to being pulled drastically off course by distant outliers.

Handling Noise & Outliers

Topic 6: Hard Margin vs Soft Margin

Balancing mathematical perfection against the noisy, overlapping realities of empirical datasets.

Strict Formulation

Hard Margin ("Zero Tolerance")

Assumes data is perfectly linearly separable (a clean, straight line can completely separate classes without a single error).

The Rule:

The Rule: No data points are allowed to cross margin boundaries.

yᵢ(wᵀxᵢ + b) ≥ 1, ∀ i

The Fatal Vulnerability:

The Problem: If there is even a single outlier or a tiny bit of noise, it will fail completely or severely overfit.

Real-World Pragmatism

Soft Margin ("Real-World Pragmatism")

Real-world data is messy and overlapping. Introduces Slack Variables (ξ), acting as a "hall pass" allowing some data points to violate the margin.

The Optimization Goal:

The Rule: Maximizes the width of the street while keeping total classification errors to a minimum.

min ½||w||² + C ∑ ξᵢ   s.t.   yᵢ(wᵀxᵢ + b) ≥ 1 - ξᵢ, ξᵢ ≥ 0

Slack Variable (ξᵢ) Meaning:

• ξᵢ = 0: Point outside the street (strictly correct).
• 0 < ξᵢ ≤ 1: Inside margin street, but on correct side.
• ξᵢ > 1: Crosses boundary (misclassified error).

Hyperparameter Optimization

Topic 7: The 'C' Parameter (Theory)

The hyperparameter C dictates exactly how strict the model should be.

Tolerant Mode

Low C (Tolerant & Generalizing)

Low C (Tolerant): Prioritizes a wide, safe margin street even if a few points sit on the wrong side, improving generalization.

Behavioral Details:

  • Margin Width: Prioritizes a very wide margin street ("wide corridor").
  • Slack Weight: Small penalty on slack variables (ξᵢ). Allows points to violate the margin.
  • Support Vectors: Many points fall inside or on the margin, generating higher support vector density.
  • Trade-off: Highly resilient to noise; slight risk of underfitting if set excessively low.
Strict Mode

High C (Closer to Hard Margin)

High C (Closer to Hard Margin): Heavily penalizes mistakes. Forces a narrow margin street to avoid errors, risking overfitting.

Behavioral Details:

  • Margin Width: Forces a narrow margin street to wrap tightly around the data.
  • Slack Weight: Massive penalty factor on mistakes; forces ξᵢ → 0 wherever possible.
  • Support Vectors: Very sparse; only 2 or 3 critical points hug the boundary.
  • Trade-off: Highly sensitive to individual noisy outliers; severe risk of overfitting.
Objective: min ½||w||² + C ∑ ξᵢ   |   Small C → Margin Maximization  •  Large C → Error Minimization
