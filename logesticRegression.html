The Purpose of Classification

Used when the variable we want to predict takes on discrete values (usually 0 or 1).

Why Linear Regression Fails

Linear regression draws an infinite straight line. Its output can be less than 0 or greater than 1. This makes no mathematical sense when we need a strict probability (like a 70% chance of rain).

The Logistic Solution

Logistic Regression takes that linear line and "squishes" it so the output is bounded strictly between 0 and 1. The output represents the probability that an item belongs to the positive class (1).

Step 1: The Raw Score (z)

Before we can calculate a probability, the model calculates a "Confidence Score".

z = θ0 + θ1x1 + θ2x2 ...
What does this mean?

z is simply the output of a standard linear equation. It is the dot product of your data features (x) and the model's trained weights (θ).

It represents the model's raw, unbounded confidence.

Example: Spam Filter

Imagine we are scoring an email:

  • Feature x1: Contains "Free Money" → Model Weight: +4.0
  • Feature x2: Contains "Meeting" → Model Weight: -2.5

If an email has "Free Money", its z-score becomes highly positive. The model is very confident it is spam. But a score of +4.0 isn't a probability!

How it squishes the score
  • g(z): The final predicted probability (0.0 to 1.0).
  • z: The raw confidence score we just calculated.
  • e: Euler's number (~2.718).
  • Notice the negative exponent (-z). If the spam score (z) is a massive positive number (e.g., +10), e-10 becomes basically 0. The fraction becomes 1/1, meaning 100% Probability!

The Cost Function: Why we use Logarithms

To train the model, we must calculate its error (Cost). A standard average doesn't work.

The Problem with MSE

If we use Standard Linear Cost (Mean Squared Error) with the Sigmoid function, the error graph becomes "wavy" (Non-Convex) with many fake local minimums. Gradient Descent gets trapped.

The Logarithmic Fix

By using Logarithms, the error graph forms a smooth, perfect bowl (Convex). It mathematically forces a massive penalty if the model is highly confident but wrong.

Cost(Pred, y) =
-log( Pred ) if true class y = 1
-log( 1 - Pred ) if true class y = 0
