What is Binary Classification?

Predicting discrete category labels instead of continuous numbers.

Definition

Classification is a supervised learning task where the target output y takes on only a small number of discrete category values rather than continuous numbers. In Binary Classification:

y ∈ {0, 1}
Continuous ProblemLinear Regression: y ∈ ℝ ≠ Discrete ProblemClassification: y ∈ {0, 1}

Positive vs. Negative Class & Labels

  • 0 (Negative Class, −): Absence of the target condition (e.g., Not Spam, Normal transaction, Benign tumor).
  • 1 (Positive Class, +): Presence of the target condition (e.g., Spam email, Fraudulent transaction, Malignant tumor).

Given an input feature vector x(i), its corresponding y(i) is called the label for that training example.

Real-World Binary Classification Tasks

• Email Filtering

Spam (1) vs. Not Spam (0)

• Online Transactions

Fraudulent — Yes (1) vs. No (0)

• Medical Diagnosis

Tumor — Malignant (1) vs. Benign (0)

Core Mathematical Objective:
Find a hypothesis function hθ(x) that outputs a calibrated probability score:
hθ(x) = P(y = 1 | x; θ)  →  Predict y = 1 if hθ(x) ≥ 0.5

Why Linear Regression Fails Here

Using a straight line with a 0.5 threshold breaks down on outliers and outputs impossible probabilities.

Tumor Size (x) vs. Malignant? (0 or 1). Observe how a distant outlier tilts the line flatter and shifts the threshold!
The Starting Dilemma

Can We Just Fit a Line and Threshold at 0.5?

In binary classification, the target is discrete: y ∈ {0, 1}. A simple intuitive idea is to fit a standard linear regression line:

hθ(x) = θ0 + θ1x

Press Next to trace why thresholding this line fails fatally on outliers!

Predict y = 1  if  hθ(x) ≥ 0.5  |  Predict y = 0  if  hθ(x) < 0.5
Threshold Cutoff: θ0 + θ1x = 0.5  ⇒  xthreshold = (0.5 − θ0) / θ1

Fatal Flaw 1: Sensitivity to Outliers

Step-by-Step Calculation Walkthrough:
1. Add Outlierx = 0.95 (far right) → 2. Flattens LineSlope θ₁ decreases → 3. Threshold Shifts0.45 → 0.62
• Before outlier: Threshold was at x = 0.45. All 4 malignant tumors (x ≥ 0.52) were correctly predicted y = 1 ✓.
• After outlier: Slope flattens → Threshold shifts right to x = 0.62.
• Clinical Disaster: Tumors at x = 0.52 and x = 0.60 now have h(x) < 0.5  ⇒  Misclassified as benign (y = 0)!

Fatal Flaw 2: Invalid Probabilities (−∞ to +∞)

A straight line outputs unbounded values. For large tumors, h(x) = 1.8; for small tumors, h(x) = −0.4. Probabilities must strictly obey:

0 ≤ P(y = 1 | x) ≤ 1

Linear regression cannot satisfy this constraint. We need an S-shaped activation function!

The Logistic (Sigmoid) Hypothesis

Squishing any real score z into a valid probability strictly between 0 and 1.

The Sigmoid Function g(z) maps any real number z into the interval (0, 1).
hθ(x) = g(θTx),   z = θTx,   g(z) = 1 1 + e−z
1. Featuresx → 2. Scorez = θTx → 3. Sigmoid g(z)P(y = 1 | x) → 4. Threshold ≥ 0.5Predict y ∈ {0, 1}
Term-by-Term & Euler's Number (e ≈ 2.718)
  • z = θTx: Raw linear score stretching from −∞ to +∞.
  • When z → +∞: e−z → 0  ⇒  g(z) = 1 / (1 + 0) = 1.
  • When z = 0: e0 = 1  ⇒  g(0) = 1 / (1 + 1) = 0.5 (decision cutoff!).
  • When z → −∞: e−z → +∞  ⇒  g(z) = 1 / (1 + ∞) = 0.
How Probability is Calculated from z:
• If z = +2: g(2) = 1 / (1 + e−2) = 1 / (1 + 0.135) ≈ 0.881 (88.1% Malignant → Predict y=1 ✓)
• If z = 0: g(0) = 1 / (1 + e0) = 1 / (1 + 1) = 0.500 (50.0% Exact Decision Cutoff)
• If z = −2: g(−2) = 1 / (1 + e2) = 1 / (1 + 7.389) ≈ 0.119 (11.9% Malignant → Predict y=0)

Probabilistic Meaning

hθ(x) = P(y = 1 | x; θ) = 1 − P(y = 0 | x; θ), so P(y=0|x) + P(y=1|x) = 1.

Example: If hθ(x) = 0.70, the patient has a 70% probability of malignancy (y=1) and a 30% chance of a benign tumor (y=0).

Decision Boundaries: Separating Class 1 from Class 0

Where hθ(x) ≥ 0.5 corresponds directly to θTx ≥ 0.

θTx ≥ 0  ⇒  hθ(x) ≥ 0.5  ⇒  predict y = 1  |  θTx < 0  ⇒  hθ(x) < 0.5  ⇒  predict y = 0
1. Linear CombinationθTx = z → 2. Sigmoid Activationg(z) = 1/(1+e−z) → 3. Threshold Decisiong(z) ≥ 0.5 ⇔ z ≥ 0 → 4. OutputClass 1

Crucial Exam Note: The decision boundary is a mathematical property of the parameters θ, NOT a property of the dataset!

Example 1: Diagonal Line

θ = [−3, 1, 1]T
−3 + x₁ + x₂ ≥ 0  ⇔  x₁ + x₂ ≥ 3
How It's Calculated:
Set θTx = 0 ⇒ −3 + 1·x₁ + 1·x₂ = 0 ⇒ x₁ + x₂ = 3.
Points above/right (x₁ + x₂ ≥ 3) → y = 1; below → y = 0.

Example 2: Vertical Line

θ = [5, −1, 0]T
5 − x₁ ≥ 0  ⇔  x₁ ≤ 5
How It's Calculated:
Set θTx = 0 ⇒ 5 − 1·x₁ + 0·x₂ = 0 ⇒ x₁ = 5.
Because of the −1 coefficient, 5 − x₁ ≥ 0 means x₁ ≤ 5 is Class 1 (left side!).

Example 3: Non-Linear Circle

z = θ0 + θ1x12 + θ2x22
With θ = [−1, 1, 1]T:  x12 + x22 ≥ 1
How It's Calculated:
Set z = 0 ⇒ −1 + x₁² + x₂² = 0 ⇒ x₁² + x₂² = 1 (Circle of radius r = 1).
Points outside circle (x₁² + x₂² ≥ 1) → y = 1; inside → y = 0!

The Cost Function: Why Logarithms Replace MSE

Mean Squared Error becomes wavy (non-convex) with the Sigmoid function; logarithms restore a convex bowl.

Why Not Squared Error?

Plugging the non-linear Sigmoid hθ(x) = 1 / (1 + e−θTx) into MSE creates a non-convex cost surface riddled with local minima. Gradient Descent gets trapped in false valleys!

Linear RegMSE → Bowl (Convex) ✓ ≠ Logistic RegMSE + Sigmoid → Wavy (Non-Convex) ✗

Piecewise Log-Loss Definition

Cost(hθ(x), y) = −ln(hθ(x))     if y = 1
−ln(1 − hθ(x))   if y = 0
How Asymptotic Penalties Work:
• If y = 1 and h = 0.99: Cost = −ln(0.99) ≈ 0.010 (confident & correct → tiny cost).
• If y = 1 and h = 0.01: Cost = −ln(0.01) ≈ 4.605 (confident & wrong → huge penalty!).
• If y = 1 and h → 0: Cost → +∞ (infinite penalty prevents false negatives!).

Why It Works (Guaranteed Global Minimum)

The logarithmic cost function is mathematically proven to be strictly convex for logistic regression! Gradient Descent will always converge to the single optimal parameter vector θ*.

Log-Loss Curve Visuals

Simplified Cost Function & Gradient Descent

Compressing the two cases into one formula and taking its derivative.

Single-Line Formulation (The Zeroing Trick)

Cost(hθ(x), y) = −y ln(hθ(x)) − (1 − y) ln(1 − hθ(x))
Why this single formula calculates both cases perfectly:
• When y = 1: (1 − y) becomes (1 − 1) = 0  ⇒  Cost = −(1) ln(h) − 0 = −ln(h(x)) ✓
• When y = 0: y becomes 0  ⇒  Cost = −0 − (1 − 0) ln(1 − h) = −ln(1 − h(x)) ✓

Full Logistic Regression Cost Function J(θ)

J(θ) = − 1 m ∑i=1m [ y(i) ln(hθ(x(i))) + (1 − y(i)) ln(1 − hθ(x(i))) ]

Averages the log-loss across all m training examples. Minimizing J(θ) is equivalent to Maximum Likelihood Estimation!

Gradient Descent Parameter Update

repeat until convergence {
θj := θj − α m ∑i=1m (hθ(x(i)) − y(i)) xj(i)
(simultaneously update all θj for j = 0, 1, ..., n)
}

Classic Exam Trap!

This update equation looks identical to Linear Regression! What makes it fundamentally different is the definition of hθ(x):

• Linear Regression: hθ(x) = θTx
• Logistic Regression: hθ(x) = 1 / (1 + e−θTx) (Sigmoid!)

Multiclass Classification: One-vs-All

Extending binary logistic regression to 3 or more categories.

Definition & Notation

Multiclass classification handles problems with more than two categories:

  • Email tagging: work, friends, family, hobby
  • Medical diagnosis: not ill, cold, flu
  • Weather: sunny, cloudy, rainy, snow

Instead of y ∈ {0, 1}, we have y ∈ {0, 1, ..., n} (n+1 classes starting at 0, or K classes 1...K).

How One-vs-All (One-vs-Rest) Works

Train K separate binary classifiers: For each class i, treat class i as the positive class (1) and lump all other K−1 classes combined into the negative class (0):

hθ(i)(x) = P(y = i | x; θ)

Making a Final Prediction

Run new input x through all K classifiers and choose the class i that outputs the highest probability score:

prediction = maxi hθ(i)(x)
Concrete 3-Class Calculation Example:
Input email x gives: h(work) = 0.15,   h(friends) = 0.78,   h(hobby) = 0.07.
⇒ Pick Class 2 (Friends) with highest confidence (78%)!

The Problem of Overfitting & Underfitting

Finding the sweet spot between a model that is too simple and one that memorizes noise.

Underfitting (High Bias)

Model: y = θ0 + θ1x (Linear)
Problem: Too simple to capture curvature. High error on both training and test data!

Optimal Fit (Just Right)

Model: y = θ0 + θ1x + θ2x² (Quadratic)
Success: Captures underlying trend smoothly and generalizes well to unseen data!

Overfitting (High Variance)

Model: y = ∑j=05 θjxj (5th-Order)
Problem: Fits noise (J ≈ 0), wiggles wildly, and fails completely on new data!

Three Ways to Fix Overfitting

1. Collect more training data (harder for a complex curve to overfit when constrained by many points).
2. Reduce the number of features (manually choose features or use model selection algorithms—though you risk discarding useful signal).
3. Regularization: Keep all features, but reduce the magnitude of parameters θj. (Ideal when many features each contribute slightly!).

Regularization: Shrinking Parameters Without Deleting Features

Adding a penalty term to the cost function forces parameters θ₁...θₙ to stay small.

Intuition Example

Suppose a 4th-order polynomial θ0 + θ1x + θ2x² + θ3x³ + θ4x⁴ is overfitting, and we want it to behave like a smooth quadratic without manually discarding features:

minθ 12m ∑ (h - y)² + 1000·θ3² + 1000·θ4²

To minimize this total cost, Gradient Descent is forced to shrink θ₃ ≈ 0 and θ₄ ≈ 0, flattening out wild oscillations!

Warning: What if λ Is Too Large?

If λ is set to a massive value (e.g., λ = 10,000), it crushes all θ₁, θ₂, ..., θn → 0, leaving:

hθ(x) ≈ θ0

This produces a flat horizontal line, causing severe underfitting (high bias)!

General Regularized Cost Function

minθ 12m [ ∑i=1m (hθ(x(i)) − y(i))2 + λ ∑j=1n θj2 ]

λ (Lambda — Regularization Parameter)

Controls the trade-off between two competing goals:
1. Fitting the training data well (first term).
2. Keeping parameters θj small so the hypothesis stays smooth and simple (second term).

Why ∑j=1n (Excluding θ0)?

By convention, we do not penalize the bias/intercept θ0! Shifting the baseline height of a function does not cause wavy overfitting.

Regularized Gradient Descent & Weight Decay

How λ modifies the update equations for both Linear and Logistic Regression.

Bias Parameter θ0 (Unpenalized)

θ0 := θ0 − α 1m ∑i=1m (hθ(x(i)) − y(i)) x0(i)

Feature Weights θj (j ≥ 1)

θj := θj − α [ ( 1m ∑ (h - y) xj ) + λm θj ]

Weight Decay Form (Factoring Out θj)

θj := θj ( 1 − α λm ) − α 1m ∑i=1m (hθ(x(i)) − y(i)) xj(i)

Because α, λ, m > 0, the factor (1 − αλ/m) is strictly less than 1 (e.g., 0.99). On every single iteration, θj is gently shrunk toward zero before subtracting the error gradient!

Regularized Logistic Regression Cost Function

J(θ) = − 1m ∑i=1m [ y(i) log(h(x(i))) + (1 − y(i)) log(1 − h(x(i))) ] + λ2m ∑j=1n θj2

The regularization sum starts at j = 1 to exclude θ0 from θ = [θ₀, θ₁, ..., θn]T. Its Gradient Descent update rule is identical to regularized linear regression above, with hθ(x) = 1 / (1 + e−θTx).

Exam Recap & Key Takeaways

Thank you! Review these three pillars before your exam.

1. Binary & Multiclass

  • Sigmoid: g(z) = 1 / (1 + e−z) bounds predictions to (0, 1) as P(y=1|x;θ).
  • Decision Boundary: θTx ≥ 0 ⇒ predict y = 1. Linear or curved with polynomials.
  • One-vs-All: Train K binary classifiers; choose maxi hθ(i)(x).

2. Convex Log-Loss & GD

  • Why Not MSE: Sigmoid in MSE creates wavy local minima.
  • Log-Loss: −y ln(h) − (1−y) ln(1−h) provides a strictly convex bowl.
  • Update Rule: Looks identical to Linear Regression, but hθ(x) uses the Sigmoid!

3. Regularization & Fit

  • Overfitting (High Variance): Fits training noise closely, fails on new data.
  • Penalty: Add +(λ/2m) ∑j=1n θj2 (never penalize θ0!).
  • Weight Decay: (1 − αλ/m) shrinks weights toward zero on every step.
