What is Supervised Regression?

Predicting continuous numerical outputs from labeled training data.

Definition — Supervised Regression

Supervised learning teaches a model from a labeled dataset where we already know the correct answers. Regression specifically predicts a continuous numerical value (like price, temperature, or age), unlike classification which predicts discrete categories (0 or 1).

Variables: One variable is the independent (predictor) variable (X)—our input—and the other is the dependent (outcome) variable (Y)—what we want to predict.

Why Modeling Choice Matters (Housing Price Example)

Suppose we want to predict the price of a 750 ft² house:

  • A straight line (pink) predicts roughly $150k.
  • A curved polynomial (blue) fits the flattening trend better and predicts roughly $200k.

How we choose our hypothesis shape directly changes our predictions!

Linear Regression with One Variable

How a learning algorithm turns training data into a predictive function h(x).

Training Set (x, y)
➔
Learning Algorithm
➔
Hypothesis Function h
x (living area) ➔ [ h ] ➔ predicted y (price)
hθ(x) = θ0 + θ1x
Why "Linear"?

Because this equation draws a straight line relating one input feature x to a predicted output hθ(x). Also called Univariate Linear Regression (single input variable).

Breaking Down Every Term

  • hθ(x): The hypothesis—our model's predicted value ŷ for input x, parameterized by θ.
  • θ0 (Theta-zero): The bias / y-intercept—the baseline predicted price when x = 0.
  • θ1 (Theta-one): The weight / slope—how much the predicted price changes for every 1-unit increase in x.

Key Question

How do we choose the best θ0 and θ1 so our line fits the data?

How Parameters θ0 and θ1 Shape the Line

Changing θ0 shifts the line up or down; changing θ1 tilts its steepness.

Case 1: Zero Slope

θ0 = 1.5, θ1 = 0
hθ(x) = 1.5 + 0·x = 1.5

Zero Slope (θ1 = 0): Input x has zero effect; the prediction is always fixed at the intercept 1.5.

Case 2: Zero Intercept

θ0 = 0, θ1 = 0.5
hθ(x) = 0 + 0.5x = 0.5x

Zero Intercept (θ0 = 0): Passes strictly through the origin (0,0) and rises by 0.5 for every +1 in x.

Case 3: Both Non-Zero

θ0 = 1, θ1 = 0.5
hθ(x) = 1 + 0.5x

Both Non-Zero: Starts at y = 1 when x = 0 and rises at slope 0.5. Adjusting θ0 and θ1 lets us position a line anywhere on the plane.

The Cost Function: Measuring Model Error

To choose the best θ0 and θ1, we need a mathematical score telling us how wrong our line is.

J(θ0, θ1) = 1 2m ∑i=1m (ŷi - yi)2 = 1 2m ∑i=1m (hθ(x(i)) - y(i))2
Optimization Goal: minimizeθ0, θ1 J(θ0, θ1)

Also known as the Squared Error Function or Mean Squared Error (MSE) (literally ½ x̄, half the mean of squared errors).

Term-by-Term Breakdown & "Why?" Questions

  • hθ(x(i)) - y(i) (Residual Error): Predicted value minus actual value for house i.
  • Why Square It (···)²?
    (1) Without squaring, positive errors (+50) and negative errors (-50) cancel out to zero!
    (2) Squaring makes all errors non-negative and penalizes large mistakes much more heavily than small ones.
  • Why 1m ∑? Averages the total squared error across all m examples so dataset size doesn't artificially inflate the cost.
  • Why the extra ½? Pure mathematical convenience! When we take the derivative of (···)² during Gradient Descent, the exponent 2 drops down and cancels ½ (2 · ½ = 1).

Vertical Residual Gaps

Vertical amber dashed segments represent (hθ(x(i)) - y(i)). Goal: Choose θ0 and θ1 so total squared vertical gaps are as small as possible.

Gradient Descent: Finding the Minimum Automatically

Instead of guessing θ values by hand, Gradient Descent walks downhill on the cost surface.

Definition & Why We Use It

Gradient Descent is an iterative optimization algorithm that repeatedly adjusts model parameters (θ0, θ1, ...) in the direction that decreases the cost function J(θ) until it reaches a minimum.

Why is it preferred? For large datasets and high-dimensional data (thousands of features), solving for θ algebraically in one shot is computationally slow and memory-heavy. Gradient Descent scales efficiently with minimal memory.

repeat until convergence {
θj := θj - α ∂ ∂θj J(θ0, θ1)
(simultaneously update for j = 0 and j = 1)
}

Term-by-Term Breakdown & "How/Why"

  • := (Assignment): Overwrite the old parameter value with the newly updated value.
  • α (Alpha — Learning Rate): A small positive constant (e.g., 0.01 or 0.001) controlling how big a step we take downhill on each iteration.
  • ∂∂θj J(θ0, θ1) (Partial Derivative / Slope): Measures the slope of the cost bowl at our current position.
    Why the minus sign? If the slope is positive (uphill to the right), subtracting a positive number moves θj left (downhill). If the slope is negative, subtracting a negative adds to θj, moving it right (downhill)!

Simultaneous Update Rule (Crucial!)

Always compute both new values temp0 and temp1 using the old θ0, θ1 before overwriting either. Updating θ0 first would corrupt the θ1 calculation!

Choosing α & Why Fixed α Still Converges

The learning rate α decides whether gradient descent crawls, converges smoothly, or explodes.

If α is Too Small

Takes tiny steps; guaranteed to go downhill, but convergence can be painfully slow (requiring thousands of unnecessary iterations).

If α is Too Large

Steps overshoot the minimum, bouncing to the opposite wall even higher up. It may fail to converge, or even diverge!

Why Fixed α Converges

You do NOT need to decrease α over time! Why? As gradient descent approaches a minimum, the slope gets flatter (closer to 0). Multiplying fixed α by a smaller slope automatically produces smaller steps until it settles at the minimum (slope = 0).

Gradient Descent Applied to Linear Regression

Substituting the Mean Squared Error cost function into the partial derivatives.

Model & Cost Function

hθ(x) = θ0 + θ1x
J(θ0, θ1) = 12m ∑i=1m (hθ(x(i)) - y(i))2

Derived Update Rules (Simultaneous)

θ0 := θ0 - α 1m ∑i=1m (hθ(x(i)) - y(i))
θ1 := θ1 - α 1m ∑i=1m (hθ(x(i)) - y(i)) · x(i)

How the Calculus Works (Why the 2 Disappears & Where x(i) Comes From)

By the chain rule: ∂∂θj 12m (hθ(x) - y)2 = 12m · 2(hθ(x) - y) · ∂∂θj (θ0 + θ1x - y)

  • The 2 cancels ½!
  • For θ0, the inner derivative with respect to θ0 is 1, leaving just the error term.
  • For θ1, the inner derivative with respect to θ1 is x(i), multiplying the error by x(i).
  • Bonus property: Because J(θ0, θ1) for Linear Regression is always a convex bowl, there are no fake local minima—Gradient Descent always finds the single global minimum!

Multiple Regression (Multiple Input Features)

Real-world predictions depend on many factors, not just house size.

Definition & Objective

Multiple Regression models the relationship between a single dependent variable (y) and several independent variables (x1, x2, ..., xn), using all known feature values together to make a more accurate prediction.

New Notation (Explained with Examples)

  • n: Number of features (in this dataset, n = 4).
  • m: Number of training examples (rows in the table).
  • x(i): The entire input feature vector of the ith training example.
    E.g., x(2) = [1416, 3, 2, 40]T
  • xj(i): Value of feature j in the ith training example.
    E.g., x3(2) = 2 (floors in house 2)

Multivariable Hypothesis & Matrix Form

From long sums to a clean, single dot product θTx.

Expanded Hypothesis

hθ(x) = θ0 + θ1x1 + θ2x2 + θ3x3 + θ4x4
Real-World Intuition
  • θ0 = Base price of any house ($80k).
  • θ1 = Value added per square foot ($0.1k/ft²).
  • θ2 = Value added per bedroom ($15k).
  • θ3 = Value added per floor ($20k).
  • θ4 = Depreciation per year of age (likely negative!).

Vectorized Matrix Form

hθ(x) = [θ0 θ1 ... θn] ⌈ x0 ⌉
| x1 |
| ⋮ |
⌊ xn ⌋ = θTx

Why Do We Assume x0(i) = 1?

The Dimension Mismatch Problem

Notice that θ has n + 1 parameters (θ0 through θn), whereas our dataset only has n features (x1 through xn).

The Elegant Solution

By prepending a dummy feature x0(i) = 1 to every training example, the feature vector x(i) also contains n + 1 elements:

θ0 · x0 = θ0 · 1 = θ0

Both vectors now match element-wise, letting us compute the entire hypothesis with a single, ultra-fast vector dot product θTx!

Gradient Descent for n ≥ 1 Variables

Generalizing the update rule to any number of features.

From n = 1 to n ≥ 1

Previously (n = 1)

θ0 := θ0 - α 1m ∑ (hθ(x(i)) - y(i))
θ1 := θ1 - α 1m ∑ (hθ(x(i)) - y(i)) x(i)

Generalized Update (n ≥ 1)

repeat until convergence {
θj := θj - α 1m ∑i=1m (hθ(x(i)) - y(i)) · xj(i)
(simultaneously update for j = 0, 1, ..., n)
}

Expanded View & Why It Works

  • For j = 0:
    θ0 := θ0 - α 1m ∑ (h(x(i)) - y(i)) x0(i)
    (Since x0(i) = 1, this is 100% identical to the old θ0 rule!)
  • For j = 1:
    θ1 := θ1 - α 1m ∑ (h(x(i)) - y(i)) x1(i)
  • For j = 2:
    θ2 := θ2 - α 1m ∑ (h(x(i)) - y(i)) x2(i)

Intuition

Every parameter θj is nudged in proportion to how strongly its corresponding feature xj contributed to the prediction error.

Tip 1: Feature Scaling & Mean Normalization

Speeding up gradient descent by putting all input features on roughly the same numerical scale.

Why Uneven Ranges Hurt Gradient Descent

Suppose x1 = size (0 to 2000 ft²) and x2 = bedrooms (1 to 5).

Because of the huge scale gap, θ descends quickly on small ranges and slowly on large ranges, creating elongated cost contours where gradient descent oscillates inefficiently back and forth on its way to the minimum.

Goal: Scale every feature into roughly -1 ≤ xi ≤ 1 (or -0.5 ≤ xi ≤ 0.5).

Two Complementary Techniques

1. Feature Scaling: Divide each input by its range (max - min), giving a new span of width 1.
2. Mean Normalization: Subtract the average (μi) from each value so the feature is centered at a new mean of 0.

Combined Scaling Formula

xi := xi - μi si
μi = Average of feature xi • si = Range (max - min) or standard deviation
Unscaled: Skinny oscillating contours vs Scaled: Circular direct path straight to the minimum!

Tip 2: Debugging Gradient Descent

How to verify gradient descent is working properly by plotting J(θ) against iteration count.

Healthy Behavior

Plot J(θ) vs Iterations: Cost drops steadily on every iteration and flattens out around 300–400 iterations once converged.

Warning Signs (Not Working)

If J(θ) is increasing or oscillating like waves: α is too large! You are overshooting the bowl. Fix: Use a smaller α.

Summary & Guarantees

Proven Guarantee

For a sufficiently small α, J(θ) is guaranteed to decrease on every single iteration.

  • α too small: Slow convergence (takes too many iterations).
  • α too large: J(θ) may fail to decrease and diverge.
  • Rule of thumb: Try ... 0.001, 0.003, 0.01, 0.03, 0.1, 0.3, 1 ...

Feature Engineering: Creating Better Inputs

Sometimes combining two raw features creates a stronger predictor than keeping them separate.

Housing Land Area Example

Suppose your dataset gives frontage (x1) and depth (x2) of a plot of land:

hθ(x) = θ0 + θ1(frontage) + θ2(depth)

Why Combine Them?

Home buyers don't care about frontage and depth separately—they care about total land area!

x = x1 × x2 = frontage × depth

Simplified model: hθ(x) = θ0 + θ1x (fewer parameters, cleaner domain intuition, more accurate predictions).

Visualizing Feature Combination

Frontage (x₁) × Depth (x₂) combines into a single meaningful predictor: Area (x).

Polynomial Regression & Choice of Features

Fitting curved, non-linear trends while still using the exact same Linear Regression machinery.

Quadratic (blue) curves back down; Cubic (green) curves up; Square Root (magenta) rises and flattens.

Quadratic vs Cubic vs Square Root

  • Quadratic: h(θ) = θ0 + θ1(size) + θ2(size)2. Problem: Parabola eventually curves back down, implying huge houses get cheaper!
  • Cubic: ... + θ3(size)3. Avoids curving downward on the right.
  • Square Root: h(θ) = θ0 + θ1(size) + θ2√size. Rises steadily and flattens naturally, matching real housing prices!

How Linear Regression Fits Curves

Simply treat powers as new features: x1 = (size), x2 = (size)², x3 = (size)³.
Then hθ(x) = θ0 + θ1x1 + θ2x2 + θ3x3 is linear in θ, so Gradient Descent works identically!

CRITICAL Warning — Feature Scaling Explodes Here!

If x1 = size has range 1 to 1,000, then:
• x2 = (size)² has range 1 to 1,000,000 (106)
• x3 = (size)³ has range 1 to 1,000,000,000 (109)!
Without feature scaling, Gradient Descent will oscillate wildly across these 109-scale differences.

Exam Recap: The Complete Regression Pipeline

Everything connects into one unified workflow.

1. The Model (hθ)

  • Univariate: h(x) = θ0 + θ1x
  • Multivariable: h(x) = θTx (with x0 = 1)
  • Polynomial: Create powers (x, x², √x) as new linear features

2. Cost & Optimization

  • Cost Function: MSE J(θ) = 12m ∑ (h(x(i)) - y(i))²
  • Convex Bowl: Guaranteed global minimum!
  • Gradient Descent: Simultaneously update θj := θj - α 1m ∑ (h - y)xj

3. Make It Fast & Accurate

  • Feature Scaling: xi := (xi - μi) / si avoids elongated contours
  • Debug with Plots: J(θ) vs Iterations verifies monotonic decrease
  • Feature Engineering: Combine raw features (frontage × depth) for intuitive models
